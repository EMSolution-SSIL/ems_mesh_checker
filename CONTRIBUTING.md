# Contributing

Contributions are welcome through GitHub issues and pull requests.

1. Create a Python 3.10 or newer virtual environment.
2. Install the package with `python -m pip install -e ".[dev]"`.
3. Run `pytest -q` before opening a pull request.

Mesh data may contain confidential model geometry. Do not commit new files
under `data/` unless their redistribution rights have been reviewed explicitly.
